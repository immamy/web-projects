# Musen
This project reconstructs the Musen Design website using pure HTML and CSS.

Technology: **HTML, CSS**

## Features
- Hand-coded HTML and CSS.
- Single-page homepage.
- Separate layouts for desktop, tablet, and mobile devices.
- Responsive Web Design (RWD).
