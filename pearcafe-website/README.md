# PearCafe Website (Vue.js)
This project reconstructs the Pearcafe website with multiple pages and navigation features.

Technology: **Vue.js, HTML, CSS, JavaScript, JSON**

## File
 `pearcafe.html`  
 `pearcafe-about-1.html`  
 `pearcafe-about-2.html`  
 `pearcafe-blog.html`  
 `pearcafe-menu.html`  
 `pearcafe-news.html`  
 `pearcafe-service.html`  
 `pearcafe-service-catering.html`  
 `pearcafe-store.html`  
 
## Features
- Multi-page website with Vue.js integration.
- Built 9-page responsive website.
- Implemented page routing and component-based structure.
- Integrated JSON data structure for content management.
- Responsive layouts for different devices.

## Optimal Display Size
- **Desktop:** 1707 × 940
- **Tablet:** 854 × 947
- **Mobile:** 500 × 947

# Website sections include:
- Home 首頁
- About the store
- Lectures
- Menu 
- Branch information
- Services
- Store events
